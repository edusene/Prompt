## O QUE É A UAZAPI

A uazapi (uazapiGO) é uma API REST premium para integração com WhatsApp.
Ela permite enviar e receber mensagens, gerenciar grupos, contatos, campanhas em massa,
configurar chatbots com IA e receber eventos em tempo real via webhooks.

A infraestrutura é totalmente gerenciada pela uazapi (hospedagem, proxy residencial,
atualizações automáticas). Não é necessário manter servidor próprio.

Site principal: https://www.uazapi.com
Documentação:   https://docs.uazapi.com

---

## AUTENTICAÇÃO

A uazapi usa dois tokens distintos:

| Token        | Uso                                                          | Header           |
|--------------|--------------------------------------------------------------|------------------|
| Admin Token  | Criar/listar instâncias, operações administrativas globais   | token: <ADMIN>   |
| Instance Token | Enviar mensagens, webhooks, grupos, contatos etc.          | token: <INSTANCE>|

O Admin Token é obtido no painel da sua conta em https://seudominio.uazapi.com.
O Instance Token é retornado na resposta ao criar uma instância.

Exemplo de header HTTP:
  token: meuAdminTokenAqui
  Content-Type: application/json

Não se usa Authorization: Bearer. O token vai no header "token".

---

## BASE URL

  https://seudominio.uazapi.com

Substitua "seudominio" pelo identificador do seu servidor/conta.
Planos por dispositivo: https://app.uazapi.com
Servidor LITE/PRO: domínio customizado configurado pelo usuário.

Todos os endpoints recebem e retornam JSON.

## ENDPOINTS — INSTÂNCIAS

As instâncias representam conexões WhatsApp individuais (números de telefone).

### Criar instância (requer Admin Token)
POST /instance/init
Body:
{
  "instanceName": "minha-instancia",
  "token": "meuTokenPersonalizado"  // opcional, gerado automaticamente se omitido
}
Resposta: { "instanceName": "...", "token": "INSTANCE_TOKEN", "status": "created" }

### Conectar / Obter QR Code (requer Instance Token)
GET /instance/connect
Resposta: { "qrcode": "base64...", "pairingCode": "XXXX-XXXX" }
Use o QR code ou o código de pareamento para autenticar o número no WhatsApp.

### Ver status da instância (requer Instance Token)
GET /instance/status
Resposta: { "status": "open" | "connecting" | "close" | "qr" }
- open: conectado e pronto
- connecting: conectando
- close: desconectado
- qr: aguardando escaneamento do QR

### Listar instâncias (requer Admin Token)
GET /instance/list
Resposta: [ { "instanceName": "...", "status": "...", "token": "..." }, ... ]

### Desconectar instância (requer Instance Token)
DELETE /instance/logout

### Deletar instância permanentemente (requer Instance Token ou Admin Token)
DELETE /instance/delete

### Reiniciar instância (requer Instance Token)
POST /instance/restart

### Atualizar nome da instância (requer Instance Token)
PUT /instance/name
Body: { "name": "Novo Nome" }

### Obter informações do perfil (requer Instance Token)
GET /instance/profile
Resposta: { "name": "...", "phone": "...", "about": "..." }

## ENDPOINTS — CAMPANHAS EM MASSA

Requer Instance Token. As campanhas incluem delays anti-ban automáticos.

### Criar campanha simples (mesma mensagem para todos)
POST /campaign/simple
Body:
{
  "name": "Promoção Black Friday",
  "numbers": ["5511999999999", "5511888888888", "5511777777777"],
  "messageType": "text",
  "message": "Olá! Aproveite nossa promoção de Black Friday! 🎉",
  "delayMin": 10,  // delay mínimo em segundos entre mensagens
  "delayMax": 30   // delay máximo em segundos entre mensagens
}

### Criar campanha avançada (personalizada por contato)
POST /campaign/advanced
Body:
{
  "name": "Campanha Personalizada",
  "contacts": [
    {
      "number": "5511999999999",
      "variables": { "nome": "João", "valor": "R$ 50,00" }
    },
    {
      "number": "5511888888888",
      "variables": { "nome": "Maria", "valor": "R$ 75,00" }

  "message": "Olá {{nome}}, seu desconto é de {{valor}}!",
  "delayMin": 15,
  "delayMax": 45,
  "scheduledAt": "2025-12-01T10:00:00Z"  // opcional, agendar envio

### Controlar campanha (pausar, continuar, parar)

## ENDPOINTS — WEBHOOK

Requer Instance Token. O webhook é a URL do seu servidor que receberá os eventos do WhatsApp.

### Configurar webhook
PUT /webhook
Body:
{
  "webhookUrl": "https://seuservidor.com/webhook/whatsapp",
  "events": ["message", "message_status", "group_participant", "call"]
}

Eventos disponíveis para subscrição:
- "message"           → mensagens recebidas e enviadas
- "message_status"    → status de entrega/leitura das mensagens
- "group_participant" → mudanças de participantes em grupos (entrar/sair/promover)
- "call"              → chamadas recebidas
- "connection"        → mudanças no status da conexão
- "qr"                → novo QR code gerado

### Ver webhook configurado
GET /webhook
Resposta:
{
  "webhookUrl": "https://seuservidor.com/webhook/whatsapp",
  "events": ["message", "message_status"]
}

### Remover webhook
DELETE /webhook

## WEBHOOK — CONFIGURAÇÃO E EVENTOS

### Como funciona
Quando um evento ocorre (mensagem recebida, status mudado, etc.), a uazapi envia
uma requisição HTTP POST para a URL configurada no seu webhook.

Sua URL deve:
1. Responder com status HTTP 200 em menos de 5 segundos.
2. Processar a lógica de forma assíncrona se necessário.
3. Estar publicamente acessível na internet (não localhost).

### Estrutura geral do payload de webhook
```json
{
  "instance": "minha-instancia",
  "event": "message",
  "data": { ...dados do evento... }
}
```

### Exemplo de servidor webhook em Node.js
```javascript
const express = require('express');
const app = express();
app.use(express.json());

app.post('/webhook/whatsapp', async (req, res) => {
  const { instance, event, data } = req.body;

  // Responder imediatamente com 200
  res.status(200).json({ ok: true });

  // Processar evento de forma assíncrona
  if (event === 'message' && !data.fromMe) {
    const from = data.from;
    const text = data.body || '';
    const type = data.type;

    console.log(`[${instance}] Mensagem de ${from}: ${text}`);

    if (type === 'text') {
      // Lógica do chatbot
      if (text.toLowerCase().includes('oi') || text.toLowerCase().includes('olá')) {
        await sendText(instance, from.replace('@s.whatsapp.net', ''), 'Olá! Como posso ajudar?');
      }
    }

    if (type === 'button_reply') {
      console.log(`Botão clicado: ${data.buttonId}`);
    }

    if (type === 'list_reply') {
      console.log(`Item de lista selecionado: ${data.listRowId}`);
    }
  }
});

async function sendText(instanceName, number, text) {
  const response = await fetch('https://seudominio.uazapi.com/send/text', {
    method: 'POST',
    headers: {
      'token': process.env.INSTANCE_TOKEN,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({ number, text }),
  });
  return response.json();
}

app.listen(3000, () => console.log('Webhook ouvindo na porta 3000'));
```

### Exemplo 1: Criar instância e conectar
```javascript
const BASE_URL = 'https://seudominio.uazapi.com';
const ADMIN_TOKEN = 'seu-admin-token';

// 1. Criar instância
const create = await fetch(`${BASE_URL}/instance/init`, {
  method: 'POST',
  headers: { 'token': ADMIN_TOKEN, 'Content-Type': 'application/json' },
  body: JSON.stringify({ instanceName: 'minha-empresa' }),
});
const { token: INSTANCE_TOKEN } = await create.json();

// 2. Obter QR Code
const connect = await fetch(`${BASE_URL}/instance/connect`, {
  headers: { 'token': INSTANCE_TOKEN },
});
const { qrcode } = await connect.json();
// qrcode é uma string base64 — exiba-a como imagem para o usuário escanear

// 3. Verificar status
const status = await fetch(`${BASE_URL}/instance/status`, {
  headers: { 'token': INSTANCE_TOKEN },
});
const { status: connStatus } = await status.json();
// connStatus === 'open' quando conectado
```

## FORMATOS E DICAS

### Formato de número
- Sempre use o código do país + DDD + número sem símbolos.
- Brasil: 55 + DDD + número = "5511999999999"
- Para grupos, use o JID: "numeroCriador-timestampCriação@g.us"

### Envio de mídia
- Prefira URLs públicas (HTTPS) para arquivos grandes.
- Base64 é aceito para arquivos pequenos (< 2MB recomendado).
- Para base64, não inclua o prefixo "data:image/jpeg;base64," — envie apenas a string base64 pura.

### Boas práticas anti-ban
- Use delay de 10–30 segundos entre mensagens em disparos em massa.
- Personalize as mensagens (evite enviar exatamente o mesmo texto para todos).
- Envie apenas para contatos que consentiram receber mensagens.
- Evite disparar mais de 200 mensagens por hora por instância.

### Códigos de resposta HTTP
- 200 / 201: Sucesso
- 400: Requisição inválida (campo faltando, formato errado)
- 401: Token inválido ou sem permissão
- 404: Recurso não encontrado (instância não existe, endpoint incorreto)
- 429: Rate limit atingido (aguarde e tente novamente)
- 500: Erro interno (tente novamente; se persistir, contate suporte)
